LoopFinder - cross-platform release package
================================================

Open the folder that matches YOUR computer before running the installer:

  Windows\   - double-click Install LoopFinder.bat inside that folder.
  macOS\     - double-click Install LoopFinder.command inside that folder.

Zip THIS "LoopFinder" folder when both platform subfolders are complete ---
that mimics indie plug-in downloads that ship Win + Mac inside one ZIP.
Any HOW_TO_* file explains which build step is still pending.
