LoopFinder - Windows installer
==============================

To install:
  1. Double-click "Install LoopFinder.bat"
  2. Accept the User Account Control (UAC) prompt that appears.
  3. Press Y to confirm.

The plugin will be installed to:
  C:\Program Files\Common Files\VST3\LoopFinder.vst3

To uninstall: double-click "Uninstall LoopFinder.bat".

No compilers or other developer tools are required.
