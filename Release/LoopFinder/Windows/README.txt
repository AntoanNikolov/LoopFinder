LoopFinder - Windows (installer inside this folder)
==============================================

Extract the enclosing "LoopFinder" bundle from the ZIP, open this folder,
then double-click "Install LoopFinder.bat".

To install (brief):
  1. Double-click Install LoopFinder.bat
  2. Accept User Account Control (UAC).
  3. Press Y to confirm.

Installs to: C:\Program Files\Common Files\VST3\LoopFinder.vst3
No compilers needed.
